# Design

초기 화면 설계와 컴포넌트 참고용 Vite 프로젝트입니다.
런타임 제품 코드는 `frontend/`와 `backend/`를 기준으로 합니다.

## 용도

- 화면 구성과 카피 참고
- 컴포넌트 스타일 비교
- 프론트엔드 구현 전 시안 확인

## 실행

```bash
cd design
npm install
npm run dev
```

## 주의

- 실제 서비스 라우팅과 API 연결은 `frontend/`에 구현합니다.
- 백엔드 DB와 CRUD는 `backend/`에 구현합니다.
- 이 폴더의 `.env` 파일은 커밋하지 않습니다.
